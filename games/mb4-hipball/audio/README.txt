DROP MP3 MUSIC FILES HERE.

The game auto-detects these on launch. If a file is present, it's used.
Otherwise the procedural chiptune synth plays.

  title.mp3   Title screen (loops)
  match.mp3   Match play (loops)
  win.mp3     Match-over screen (one-shot, optional)
  lose.mp3    Reserved (one-shot, optional)

Recommended source: https://opengameart.org/content/aztecmaya-style-music
by Alexandr Zhelanov, CC-BY 4.0. Suggested mapping:

  Their 2_face_to_face.mp3  ->  rename to  match.mp3
  Their 1_great_pyramids.mp3 ->  rename to  title.mp3
