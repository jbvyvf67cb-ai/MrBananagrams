DROP MP3 ANNOUNCER VOICE CLIPS HERE.

The game looks for these filenames. Each is a short (1-2 second) shout.
If a file is present, it plays. If missing, the game falls back to a
short synth noise — a horn for powerups, a blast for rally start, a
whoop for scores. No speech imitation, no robot voice.

GAME EVENTS (broad coverage by free voice packs):
  fight.mp3         start of every rally
  raya.mp3          after a regular score (ball past the end line)
  hoop.mp3          after a hoop score (+3 rayas)
  you_win.mp3       match-over winner banner

POWERUP NAMES (these need to say the specific powerup name):
  jaguar_step.mp3        "JAGUAR STEP!"
  lightning_knee.mp3     "LIGHTNING KNEE!"
  obsidian_edge.mp3      "OBSIDIAN EDGE!"
  stone_hide.mp3         "STONE HIDE!"
  quetzal_cloak.mp3      "QUETZAL CLOAK!"
  hummingbird_wings.mp3  "HUMMINGBIRD WINGS!"
  smoke_trail.mp3        "COPAL SMOKE!"
  twin_sun.mp3           "TWIN SUN!"

EASIEST PATH: record them yourself on your phone. Shout each name with
maximum arcade-announcer gusto. Quick-trim. Export as MP3. Drop in.

For the generic events, free packs like VoiceBosch's "Mr. Happy" on
OpenGameArt have phrases like "Fight!", "Victory!", "You Win!" that
work fine — just rename to match the game's filenames.
